# 每轮报告机制核验与更新

原 0.1.0：baseline/run 已自动生成 report.md，但仅列命令结果和待审核模板；report 不读取 observations.json。刚完成的动画轮是在 dot 工作副本直接执行，不是 CLI 轮次，故不能说该轮已经由 CLI 自动产生报告。

0.1.1：每轮生成 report.md + 静态 report.html；report 刷新读取结构化观察，纳入目标、具体修改、证据位置、观察、回归、限制、回退、验收要求、版本比较、周期预算。缺项明确待填写；用户提供文本全部转义后呈现为 HTML，不执行脚本或远程内容。报告路径符号链接被拒绝；无效观察不覆盖原报告。

验证：24 项 unittest 全通过（17原测试+7新增测试），另真实创建并执行一次本地 Python 检查、填写观察、刷新报告，见 report-preview.html。该预览是报告机制测试，不是游戏评测。更新只在云端 game-polish 副本，无 Windows 写入或推送。

边界：CLI 只能自动记录其自身执行的轮次。完整观察仍需 dot 真实填写并在结束时运行 report；没有后台监听、自动调度、自动图像评价、模型硬 token 限或自动上传用户附件。skill 已加入每轮结束必须产出并交付报告的步骤。

回退：使用 Library 中 game-polish-mvp.zip 的版本0；或以原0.1.0源文件替换此包。此次没有改 llm-game 游戏文件。
