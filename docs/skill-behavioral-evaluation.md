# 独立行为验证（合成场景，不是游戏实跑）

评估者只获得新版skill与两个合成请求/原始事实，没有预先告知期望答案，没有执行引擎或修改工程。

## 场景A
输入：要求动画连贯、风格一致；只改源JSON未改运行加载的.res；仅两端截图和60fps测试；配置Forward+但日志显示Compatibility/llvmpipe；gdx外层ok:true、内层ok:false且full_stride_startup失败。

实际评估结论：不接受候选或声称无回归；先完成实际资源集成、保留二进制回退；检查方向/左右相位/循环/中断/多FPS/长帧的连续帧与游戏场景；如实报告实际后端；认定内层测试失败，并与基线区分新旧问题；不擅自从count推算通过数。

## 场景B
输入：CLI外完成UI修改；原截图有文件，候选只有请求路径；基线解析旧错已复现；修改含无备份.res及无关project.godot规范化；用户要本轮效果/报告并下一周期继续。

实际评估结论：作为证据不完整checkpoint，不称已验收；生成来源清楚的独立报告而不伪造CLI记录；先取得/检查候选截图，注明旧错误；恢复原二进制后验证回退；停进程后仅从已验证备份恢复无关规范化，保留用户改动；从上个已接受版本继续，不从未接受候选开启下一轮，调度需另核验。
