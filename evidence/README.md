# Evidence policy

The toolkit has been exercised on a private project through two bounded title-screen changes. Private captures, patches, and run manifests are kept under `private-llm-game/`, which is ignored by Git and **must be excluded from public distributions and release archives**. That directory is a local review artifact, not part of this open-source example.

The public Neon Dash example uses original vector assets and can be redistributed separately. Do not infer a general game-quality claim from a passing parser or a title-screen example. The two private passes included rejected layout variants; accepting only changes with sufficient evidence is a core part of the workflow.
